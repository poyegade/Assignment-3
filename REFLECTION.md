# Reflection

## 1. What did you ask Copilot to help you build? How did you break down the problem?

I used GitHub Copilot to help me build a Soccer Team Manager web application. I divided the project into smaller tasks including creating the HTML structure, generating CSS styling, and implementing JavaScript functionality.
